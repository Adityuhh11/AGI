# macOS M1: the core launcher, on screen

Spec: `docs/superpowers/specs/2026-10-29-macos-design.md` (sections 5.1, 5.4, 5.14, 5.15). Branch `feat/macos`. M0 (it compiles) is done. Same rules as M0:
Windows and Mac code apart, one commit per task, the `launcher-macos` job is the compiler (everything here is Objective-C through cgo, written without a Mac).

Owner's decision on the cloak: none first. The panel is ordered in and out; a cloak is added only if the friend sees a stale or blank first frame.

## Tasks

1. **Panel** (`internal/panel`): `platformWindow` per system (Windows: its options as now; Mac: a non-activating `NSPanel`, floating, on every Space and over full-screen apps,
   no shadow). `native_darwin.go` + `native_darwin.m` replace the M0 no-ops: frontmost app (pid, never ourselves), is it running, activate it, order the window in and out
   (`cloak` on a Mac is just that), the screen under the mouse (work area in points, top-left origin, scale 1 so `place` is reused), set the frame, keep the top edge on resize.
   Every AppKit call runs on the main thread. A window is handed to C as a number, never a Go pointer.
2. **Dock and menu** (`internal/dock`): the launcher is an accessory app (no Dock icon). While Settings, the guide, Notes or the chat is open it becomes a regular one
   (Dock icon, ⌘Tab, menu bar) and goes back when the last closes. `settingsui.Window` reports opens and closes; the timer overlay does not count. A real application
   menu (Edit included, without which ⌘C and ⌘V do nothing in the page) is set on start (`platformSetup`).
3. **Icons** (`apps/icon_darwin.go`+`.m`): `NSWorkspace.iconForFile`, drawn into a 64 px bitmap, encoded as PNG.
4. **Tray**: a template image (`icon-template.png`, black with the ring's alpha) so macOS tints it for light and dark.
5. **App list freshness**: the folder watcher is M3, so the list is refreshed when the bar opens if it is over a minute old (`Catalog.RefreshIfStale`, a directory read).
6. **Pages**: key glyphs (⌃ ⌥ ⇧ ⌘ ↩ ⌫ ␣) and Mac wording (Finder, default browser) from one `lib/platform.ts` that reads the web view's user agent. In-page shortcuts stay on Ctrl
   (they work on a Mac and avoid the menu's ⌘ keys); the hints show ⌃. Moving them to ⌘ is polish (M5).

## Done when

`launcher-macos` is green with all of it, Windows is unchanged and green, and the friend can run the short checklist (spec section 10: items 2, 3, 5).
