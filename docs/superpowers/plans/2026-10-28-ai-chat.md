# Plan: Omni AI chat

Spec: `superpowers/specs/2026-10-28-ai-chat-design.md`. Spike and pins: `eval/2026-10-28-chat-model.md`, ADR 0008. Branch `feat/ai-chat`.
Each step ends with its tests green (`go vet ./...`, `go test ./...`, `npm test`, `npm run check`) and a small commit.

## Steps

1. **Config.** `[chat]`: `enabled`, `hotkey`, `load` (`when_asked`, `at_start`), `unload_after_minutes`, `context_tokens`, `keep_history`,
   `history_days`, `thinking`. Defaults, validation (hotkey differs from the launcher's and the clipboard's; choices; ranges), clone.
   Tests in `config_test.go`.
2. **`internal/llm`: pins and install.** `Pins` (llama.cpp b11970 Vulkan, QAD Q4_0 at the pinned revision), `Layout` (`chat\llama`,
   `chat\models`, manifest written last), `Setup` (download both with `enginesetup.Downloader`, unzip, check, state, cancel, remove).
   Tests with a local file server, as `enginesetup` does.
3. **`internal/llm`: the server.** `ChooseDevice` (a port of the engine's rule, tested on listings), `Server` (start on the chosen device or
   the CPU, wait for `/health`, kill with the whole tree, restart once, idle unload on an injected clock, `Ensure`, `State`, `Unload`,
   `Touch`), the job object so it dies with Omni. Tests: device choice, idle timer, a stand-in server script for start, restart,
   failure and unload. One real test marked `model` that starts the real server when `OMNI_CHAT_DIR` is set.
4. **`internal/chat`: conversations.** `Store` (one JSON file per chat, atomic, ids cannot escape, list/search/delete/expire/clear),
   `Conversation` and `Message`. Table tests.
5. **`internal/chat`: context and streaming.** `Window` builder (system prompt, whole-turn trimming, reserve, oversize refused, thinking
   stripped from history), SSE client for `/v1/chat/completions` (content, reasoning, usage, the `stop` and `enable_thinking`
   fields), `/tokenize` count. Tests against a fake SSE server.
6. **`internal/chat`: Service.** Bound methods: `Send`, `Stop`, `New`, `Open`, `List`, `Delete`, `ClearHistory`, `SetThinking`,
   `SetOnTop`, `State`. Events to the page: `chat:token`, `chat:done`, `chat:state`. One generation at a time; closing the window
   stops it. Tests with a fake model.
7. **Settings.** A `ChatSettings` service (view, turn on with progress, cancel, remove, the behaviour setters, unload now, clear
   history) and the page `lib/settings/OmniAI.svelte`, a section in `Settings.svelte`.
8. **The window.** `chatSpec` and `NewChatWindow`; `Chat.svelte` and `lib/chat/` (pure parts tested with node: the message list
   reducer, the batching of tokens, the keys); route `#chat`; `main.ts`.
9. **Ways in.** Palette provider for `ask` / `ai` / `chat` and `ask:` mode (rows, Enter, off state), the tray item, the hotkey
   (`Panel` gains a way to run a function instead of filling the bar), warm-up on intent, wiring in `cmd/omni/main.go`, the
   removal of the `chat` folder in `--remove-data`.
10. **Check by running it.** Build the app, open the window at 125%, ask, stop, think toggle, history, trim line, unload and reload,
    CPU fallback; `panelbench` with chat on and off; an answer during a sync. Write the numbers in `eval/`.
11. **Docs.** `STATUS.md`, `ARCHITECTURE.md`, `docs/README.md`, the README privacy row and `AGENTS.md` if a rule moved.

## Done when

The checks in the spec's section 10 hold, the owner has used it, and the branch is merged into `dev` (and so into PR 39).
