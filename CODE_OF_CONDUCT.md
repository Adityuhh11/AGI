# Code of Conduct

Omni is a small project with one maintainer. The rule is short: be kind and be specific.

- Disagree with the code, the design or the decision, not the person.
- Assume good faith, and say plainly what you need when something is unclear.
- Harassment, insults, personal attacks, discrimination and publishing other people's private information have no place in issues, pull requests,
  reviews or discussions.

This applies everywhere the project is discussed in public: this repository and the spaces linked from it.

## Enforcement

The maintainer may edit, hide, lock or delete comments, close issues and pull requests, and block people who break these rules, without warning
for serious cases.

To report a problem, use **Report a vulnerability** on the repository's Security tab
(https://github.com/Adityuhh11/Omni/security/advisories/new). It is private, and it is the one channel the maintainer reliably sees; say in the
report that it is about conduct, not security. For something about the maintainer, say so, and ask for a second opinion from GitHub through
[their report form](https://github.com/contact/report-abuse).

This is a short version in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which
is a fine thing to read if you want the long one.
